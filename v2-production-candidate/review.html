Saytda nə dəyişəcək?

Hazırda heç bir vizual və məzmun dəyişikliyi yoxdur. Yeni təsdiqlənmiş xəbər və nəticə yoxdur; nümunə məlumat əlavə edilməyib.

  • V11 desktop və mobil dizayn: dəyişməz.
  • Bütün 208 idmançı profili, onların tarixçəsi və 351 nəticə sətri: dəyişməz.
  • Bütün mövcud səhifələr, naviqasiya, axtarış, filtrlər, şəkillər və PDF-lər: canlı V1 nüsxəsi.

V2 inteqrasiyasına daxil edilənlər

  • Xəbərlər, yarışlar, protokollar, foto albomlar, rekordlar və sənədlər üçün admin alətləri.
  • XLSX, DOCX və mətnli PDF protokollarının analizi; idmançı uyğunlaşdırılması və sətir-sətir təsdiq.
  • Pauerliftinq və Benç-press üçün ayrı nəticələr; tarixçənin qorunması və mümkün rekord xəbərdarlıqları.
  • Yoxlama üçün qaralama PR, mənbə hash-ləri, ehtiyat nüsxələri və rollback yoxlamaları.

Admin alətlərini yuxarıdakı ayrıca staging keçidində yoxlayın. Bu statik ön baxış GitHub girişini təqlid etmir və istehsal repozitoriyasına yazmır.

İstehsal aktivləşdirilməsi gözləyir

Staging Worker və onun GitHub App-i yalnız preview repozitoriyası üçün saxlanılıb. İstehsal aktivləşdirilməsi ayrıca təsdiq və minimal icazəli istehsal GitHub App avtorizasiyası tələb edir.

Skan PDF-lər üçün OCR lazımdır; qeyri-standart cədvəllər uyğunlaşdırma tələb edə bilər. Yeni idxal/yayım alətlərinin real administrator sessiyasında tam qəbul yoxlaması hələ tamamlanmayıb.

Bu səhifə yalnız inteqrasiya yoxlaması üçündür; saytın mövcud dizaynına və naviqasiyasına daxil edilməyib.
